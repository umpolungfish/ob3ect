A local model path is not a cloud model ID

The fallback chain handed /home/mrnob0dy666/.modelz/ADULTBB to OpenRouter as a
model id and got back "is not a valid model ID" — a local checkpoint is a
filesystem path, and it belongs only to a provider that loads paths. --model now
reaches the provider it was named for, and a path is never passed to a cloud
endpoint.

And exhaustion reports every provider's own reason rather than the last one's. In
this run there were three different faults — the local model returned nothing,
OpenRouter rejected a path, DeepSeek 400'd — and only the third was printed,
which points the reader at the wrong one.
