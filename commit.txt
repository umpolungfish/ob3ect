Make the logical circuit explicit in ob3ect generation

Every generated ob3ect now carries an ASCII logical-circuit diagram with the
edge weights explicit, the terminal counterpart of the SVG. auto.py computes it
(_generate_ascii_circuit, over imscr_wiring + render_wiring_ascii) and stores it
on the artifact; core.py serializes it as the ascii_circuit field; the run block
prints it under "Logical circuit (edge weights explicit)". A standalone
circuit_ascii.py renders any glyph word or ob3ect JSON. The weight on each edge
is the Belnap register delta, with the fork/fuse ports (T,F,o,i) and «B» paradox
marks shown, so the logical circuitry is legible in the terminal.
