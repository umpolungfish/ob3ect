Feed SIXTEEN_3 carriers to the ASCII circuit

_carriers_16_3 runs the bootstrap through the trilattice register machine and
returns one carrier name per opcode (the register after each op). Both the
ob3ect generation path (_generate_ascii_circuit) and the standalone
circuit_ascii.py now pass these to render_wiring_ascii, so the logical circuit
in the terminal shows the full-lattice edge weight -- ENGAGR's t+f deposit and
the A paradox -- instead of a bare dot. Falls back to the FOUR-valued reading
when the trilattice machine is unavailable.
