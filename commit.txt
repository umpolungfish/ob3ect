Minted sixteen3_gpu_tensor_kernel: a GPU tensor kernel for the SIXTEEN_3
trilattice's register gates, batched across many registers at once.
Grounded, tri-ancestral verdict T (a real fork/fuse pair with EVALT and
EVALF transforming both arms before the fuse, not an identity closure),
tier O2dag. Context file records why: Reg16_3's own gates (union,
meet_t/join_t, meet_c/join_c, the three leq_* orders, the three lane-swaps)
are already fixed, data-independent per-lane bit ops, and the trilattice's
catalog tuple shares its Stoichiometry axis ("many identical") with
real_swendsen_kernel and ising_navigator, the two entries here that already
name a real CUDA kernel as their implementation.

Built the real kernel from this in mOMonadOS (src/gpu_sixteen3.rs, commit
in that repo): three CUDA kernels compiled at runtime via NVRTC, verified
bit-for-bit against the CPU scalar implementation at up to 20 million
register pairs, zero mismatches.
