display: 3-lane (TRUE/BOTH/FALSE) bootstrap sequence in report()

Phase 4 of Ob3ectArtifact.report() now renders the token sequence as three
lane-columns instead of one linear list, so the reader sees where each
operation commits in the T/F register:

  TRUE  = commits a true polarity   (EVALT evaluate-true, AFWD advance-forward)
  FALSE = commits a false polarity  (EVALF evaluate-false, AREV advance-reverse)
  BOTH  = acts on the shared register (structural + dialetheia: everything else)

Sequence order is preserved top-to-bottom; each step appears only in its lane.
Added LANES, opcode_lane(), and render_lane_columns() to core.py; wired into
report() Phase 4. Lane partition follows the existing opcode semantics
(EVALT/EVALF and AFWD/AREV are the only polarity-committing ops).
